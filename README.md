# terraform-practice

Учебный проект по OpenTofu/Terraform.

## Что здесь
- `main.tf`: ресурс `terraform_data` с переменной, провизионером и output

## Как запустить
tofu init
tofu plan
tofu apply
tofu destroy

## Чему научился
- цикл init → plan → apply → destroy
- переменные, outputs, state
- разница между изменением на месте (~) и пересозданием (-/+)
